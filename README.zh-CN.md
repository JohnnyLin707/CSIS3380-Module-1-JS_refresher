# JS Refresher：综合挑战（JS 复习刷题应用）

🔗 **在线访问：** https://johnnylin707.github.io/JS_refresher/

一个用于复习现代 JavaScript 基础知识的交互式刷题应用。作为课堂复习练习（CSIS 3380 – 全栈开发与 JavaScript）设计，同样适合自学自测。

所有题目、答案和解析均为**中英对照**显示，可以同时用两种语言学习。

## 功能特点

- **5 个主题** — 语句与表达式、不可变性、箭头函数与回调、展开运算符与解构、数组方法
- **每个主题 5 道题**（共 25 题），每轮随机打乱顺序
- **额外练习** — 每个主题另有 8 道加练题（共 40 道），放在各自的独立页面里，从侧边栏进入
- **计分规则** — 答对 +1 分，答错 −1 分，顶部实时显示总分
- **理论卡片** — 每个主题开始时展示一句核心概念总结
- **中英对照** — 每道题的题目、答案和解析都在英文原文下方显示中文翻译
- **即时反馈** — 提交答案后立即显示正确答案和简短解析

## 快速开始

无需构建、无需安装依赖 —— 纯 HTML/CSS/JavaScript。

**方式一：直接打开**

用任意现代浏览器打开 `index.html` 即可。

**方式二：本地起服务**（推荐）

```bash
# Python
python -m http.server 8080

# 或 Node.js
npx serve .
```

然后访问 <http://localhost:8080>。

## 玩法说明

1. 在左侧边栏选择一个主题。
2. 阅读第一道题上方显示的理论卡片。
3. 输入答案后点击 **Submit Answer**（判定不区分大小写）。
4. 查看正确答案和解析（中英对照），点击 **Next Question** 进入下一题。
5. 5 道题完成后会显示完成提示，总分显示在页面顶部。

> 提示：答案判定采用不区分大小写的"包含"匹配，所以输入 `Statement` 也算答对 `statement`。

## 额外练习

侧边栏的 **Extra Practice（额外练习）** 区域为每个主题提供了一个独立页面，每个页面含 **8 道加练题**（共 40 道）。它们使用与主页面完全相同的布局、计分规则和中英对照显示格式；每轮结束后可以用 **Restart Round（再来一轮）** 按钮重新打乱题目。

## 项目结构

```
JS_refresher/
├── index.html   # 页面布局：侧边栏（核心主题 + 额外练习入口）、理论卡片、答题卡片
├── script.js    # 主页面的题库（中英对照数据）+ 答题逻辑
├── style.css    # 样式，包括中文翻译行的样式
├── extras/                      # 额外练习（每个主题一个文件夹）
│   ├── quiz-engine.js           # 所有额外页面共用的答题逻辑
│   ├── statements/              # index.html + questions.js
│   ├── immutability/
│   ├── functions/
│   ├── data/
│   └── arrays/
├── README.md        # 英文版说明
└── README.zh-CN.md  # 中文版说明（本文件）
```

主页面题库位于 `script.js` 顶部的 `topicBank` 对象中，额外练习的题库位于对应 `extras/<topic>/questions.js` 中。每道题包含以下字段：

| 字段 | 内容 |
| --- | --- |
| `q` / `qcn` | 英文题干 / 中文题干 |
| `a` / `acn` | 接受的英文答案 / 中文答案 |
| `e` / `ecn` | 英文解析 / 中文解析 |

想给主页面添加题目或主题，只需编辑 `topicBank`，无需改动其他代码。
想给额外练习加题，编辑对应 `extras/<topic>/questions.js` 里的 `extraQuestions` 数组即可。

## 技术栈

原生 HTML5 + CSS3 + JavaScript（ES6+），不依赖任何框架和第三方库。
